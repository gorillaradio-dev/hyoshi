Iscrizioni (enrollment fees)

L'iscrizione (enrollment fee) è la quota una tantum che lo studente paga per essere "in regola" come associato. Ha una validità a tempo (di default 12 mesi) e determina lo stato attivo dello studente: senza un'iscrizione valida, lo studente è in Pending a prescindere dai pagamenti mensili.

Modello EnrollmentFee

File: app/Models/EnrollmentFee.php. Tenant-scoped, UUID. Una riga = una iscrizione registrata.

CampoNote
student_idFK → students.
payment_idFK → payments: il pagamento effettivo che ha coperto l'iscrizione.
expected_amountQuota attesa in centesimi.
starts_atData inizio validità.
expires_atData fine validità (calcolata: starts_at + enrollment_duration_months).

Durata configurabile per tenant

La durata dell'iscrizione vive nei settings del tenant, non è hardcoded: 

$durationMonths = tenant()?->settings['enrollment_duration_months'] ?? 12;

Default 12 mesi. Un tenant può scegliere un'altra durata (es. anno sportivo settembre-agosto = 12 mesi spostati, oppure 6 mesi per pacchetti semestrali).

Rinnovo anticipato

Una caratteristica importante di EnrollmentFeeService::registerEnrollment è che gestisce il rinnovo anticipato: se lo studente ha già un'iscrizione ancora valida, la nuova parte dalla scadenza dell'attuale, non da oggi. Risultato: non si "perde" il tempo residuo. 

$latestEnrollment = $this->getLatestEnrollment($student);

if ($latestEnrollment && $latestEnrollment->expires_at->isFuture()) {
    $startsAt = $latestEnrollment->expires_at;   // rinnovo anticipato
} else {
    $startsAt = Carbon::today();                  // prima iscrizione o iscrizione scaduta
}

$expiresAt = $startsAt->copy()->addMonths($durationMonths);

Registrazione: cosa succede

EnrollmentFeeService::registerEnrollment(Student $student, int $amount, ?string $notes) in sequenza:

  1. Legge la durata dai settings del tenant (default 12).
  2. Decide starts_at (rinnovo anticipato vs prima iscrizione/scaduta).
  3. Calcola expires_at = starts_at + durationMonths.
  4. Crea un Payment con payment_method = Cash e paid_at = now().
  5. Crea l'EnrollmentFee collegata al Payment.
  6. Ritorna il Payment creato.

Verifica della validità

Due metodi di servizio rispondono a "lo studente è in regola?".

  • hasValidEnrollment(Student $student): bool — true se l'ultima iscrizione esiste ed è ancora valida (expires_at non passata). Questo è il metodo chiamato da Student::effectiveStatus per decidere Active vs Pending.
  • isEnrollmentExpired(Student $student): bool — true solo se ha avuto un'iscrizione e questa è ora scaduta. false se non ha mai fatto iscrizione (utile per distinguere "mai iscritto" da "scaduto").

UI

La registrazione dell'iscrizione avviene tramite il dialog resources/js/components/register-enrollment-dialog.tsx, lanciato dalla pagina Tenant/Student/Show.tsx. L'endpoint backend è: 

POST app/{tenant}/students/{student}/payments/enrollment
→ StudentPaymentController::registerEnrollment

L'iscrizione è disaccoppiata dalle quote mensili: pagare il mese non rinnova l'iscrizione, e viceversa. Sono due flussi separati che convivono nello stesso payments ma con tipologie attese diverse (enrollment_fees vs monthly_fees).
