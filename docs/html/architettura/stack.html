Stack tecnologico

TrainerHub è costruito sul Laravel React Starter Kit: un monolite full-stack con backend Laravel e frontend React resi insieme da Inertia.js. Le scelte riflettono la realtà del progetto al commit corrente — versioni reali da composer.json e package.json.

Backend

TecnologiaVersioneRuolo
PHP^8.2 (dev 8.3/8.4, deploy 8.4)Runtime backend; CI testa su 8.4 e 8.5.
Laravel^12.0Framework HTTP, routing, ORM Eloquent, queue, cache.
stancl/tenancy^3.9Multi-tenancy single-database con global scope e identificazione path-based.
Laravel Fortify^1.30Backend di autenticazione (login, registrazione, 2FA, recovery codes).
Inertia for Laravel^2.0Adapter server-side per Inertia: trasforma le response in pagine React.
Laravel Wayfinder^0.1.9Genera client TypeScript tipizzato delle route Laravel (Vite plugin).
Laravel Tinker^2.10REPL per debug interattivo.
Laravel Pint^1.24 (dev)Code style per PHP (preset Laravel).
Laravel Pail^1.2 (dev)Tail dei log applicativi in tempo reale.
Pest^4.4 (dev)Test runner sopra PHPUnit con plugin Laravel.

Frontend

TecnologiaVersioneRuolo
Node22 (CI)Runtime build e dev server.
React19.xUI library (con React Compiler abilitato via Babel plugin).
TypeScriptvia typescript-eslint ^8Tutti i file .tsx sono TS. No any, no !, no as unsafe.
Inertia React adapter@inertiajs/react ^2.3Riceve le pagine dal backend, fa client-side routing.
Tailwind CSS^4.1 (via @tailwindcss/vite)Utility-first styling con la v4 (no tailwind.config.js classico).
shadcn/ui(componenti copiati in components/ui/)Base UI obbligatoria — niente componenti hand-rolled quando shadcn ne ha uno.
Radix UI primitives@radix-ui/* (dietro shadcn)Accessibility e behavior dei componenti shadcn.
Vite(via @vitejs/plugin-react ^5)Dev server e bundler; integra Wayfinder.
ESLint + Prettiereslint ^9, prettier ^3Lint e formatting; npm run lint autofixa import order.

Dati e infrastruttura

TecnologiaNote
MySQL 8Locale: root, no password, database trainerhub. Produzione: connessione MySQL standard (vedi config/database.php).
UUIDChiavi primarie ovunque via trait HasUuids. Anche tenants.id usa UUID (generato da Stancl\Tenancy\UUIDGenerator).
Importi monetariSempre interi in centesimi. Mai float per il denaro.
File storagePredisposto per S3-compatible (path prefissati con tenants/{tenant_id}/). Locale: filesystem default Laravel.

CI/CD

WorkflowCosa fa
deploy.ymlSu push a main: SSH deploy a /var/www/hyoshi-staging via appleboy/ssh-action. Composer install no-dev, migrate force, build con retry 3x.
tests.ymlPest su PHP 8.4 e 8.5, Node 22. Trigger su push/PR a main e production.
lint.ymlPint (PHP) + Prettier + ESLint. Stesso trigger di tests.
sync-docs.ymlMirror di docs/html/ verso gorillaradio-dev/go-docs per il portale centrale (docs.gorillaradio.dev).
claude.yml · claude-code-review.ymlTriage e review automatici con Claude Code GitHub Action.

Predisposto (non ancora attivo)

  • Laravel Cashier (Stripe) — abbonamenti del trainer alla piattaforma. Sprint 2 nel piano originale (vedi docs/architecture.md).
  • Stripe Connect — colonna tenants.stripe_account_id già prevista per i pagamenti futuri degli allievi.
  • Account allievi — colonna students.user_id nullable già in schema, attivabile lato applicativo.
  • Custom domain per tenant — supportato dal package stancl/tenancy, abilitabile cambiando solo il middleware di identificazione.

Le versioni qui sopra sono quelle dichiarate nei manifest. Per le versioni effettivamente installate, leggi i lock file: composer.lock e package-lock.json.
