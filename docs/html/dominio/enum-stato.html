Enum di stato e tipo

Tutti i valori a dominio chiuso del progetto sono espressi come backed enum PHP 8.1. Vivono in app/Enums/, sono persistiti come stringhe, e sono usati come cast sui modelli Eloquent. Questo sposta la validazione dei valori ammessi sul sistema dei tipi: stati non validi diventano impossibili a livello di compilazione.

Perché backed enum

  • Auto-documentazione. L'enum elenca tutti i casi possibili: leggere la classe è più chiaro che cercare gli where('status', '...') sparsi nel codice.
  • Refactoring sicuro. Rinominare un caso è un cambio nominale: il compilatore segnala ogni uso non aggiornato.
  • Match exhaustive. Con match() il linter rileva i casi non gestiti.
  • Sicurezza ai bordi. Un valore arbitrario dal DB o da una request che non è uno dei casi → eccezione, non valore "fantasma".

StudentStatus

File: app/Enums/StudentStatus.php.

enum StudentStatus: string
{
    case Pending = 'pending';
    case Active = 'active';
    case Suspended = 'suspended';
}
CasoValoreSignificato
PendingpendingStudente senza iscrizione valida (mai iscritto o iscrizione scaduta). Calcolato.
ActiveactiveStudente con iscrizione valida e non sospeso. Calcolato.
SuspendedsuspendedSospeso manualmente dal trainer. Persistito su students.status.

Lo stato esposto dall'API è student->effective_status, non student->status. Vedi Studenti e gruppi · stato effettivo per la regola di calcolo.

PaymentMethod

File: app/Enums/PaymentMethod.php.

enum PaymentMethod: string
{
    case Cash = 'cash';
}

Per ora c'è solo Cash. È un enum (anziché una colonna libera) per facilitare l'aggiunta futura di Transfer, Card, Online (Stripe Connect) senza riscrivere i call site.

DocumentType

File: app/Enums/DocumentType.php.

enum DocumentType: string
{
    case MedicalCertificate = 'medical_certificate';
    case IdentityDoc = 'identity_doc';
    case PrivacyConsent = 'privacy_consent';
    case Other = 'other';
}

Tipologia del documento dell'allievo. MedicalCertificate è il caso che ha expires_at obbligatorio (gli altri sono opzionali).

DocumentStatus

File: app/Enums/DocumentStatus.php.

enum DocumentStatus: string
{
    case Pending = 'pending';
    case Delivered = 'delivered';
    case Expired = 'expired';
    case ExpiringSoon = 'expiring_soon';
}

Stato del documento. ExpiringSoon è l'alert per certificati medici che scadono nei prossimi 30 giorni.

Convenzioni di codifica

  • Naming: il caso è PascalCase; il valore persistito è snake_case. Convenzione consolidata in tutto il progetto.
  • Cast nei modelli: 'status' => StudentStatus::class nella $casts array.
  • Niente magic strings nelle FormRequest: usare 'in:'.implode(',', array_column(StudentStatus::cases(), 'value')) o Rule::enum(StudentStatus::class).
  • Niente magic strings nei test: sempre StudentStatus::Active->value (mai 'active' letterale).

Quando aggiungi un nuovo caso a un enum esistente, cerca tutti i match($x) { ... } nel codice: PHP non garantisce exhaustiveness a runtime, ma il tuo PR dovrebbe coprire tutti i siti d'uso esistenti.
